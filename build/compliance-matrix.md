## Contract Alignment

The canonical files under `contracts/` are authoritative for the concrete payload,
route, event, and error shapes. The matrix rows describe required implementation
behaviour; use the linked OpenAPI files and shared JSON Schemas to validate exact
fields. Blueprint `contract-pack.json` files are derived source manifests and do not
override the canonical contract tree.
